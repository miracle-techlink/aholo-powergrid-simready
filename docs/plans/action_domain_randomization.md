# 动作随机化与独立评测

现有 [cup-robustness](../cup-robustness.md) 已实现物性采样、固定控制器执行、参数读回和失败计数。[反馈候选](../cup-stability-candidate.md)已实现但尚未完成新留出成对物理验证；域随机化策略训练尚未实现。

## 下一步

1. 先在 development 样本定位滑移、姿态与释放问题，冻结反馈候选和预算。
2. 在未用于调整的新 heldout 样本上成对比较原控制器和候选；保持几何、频率与任务门槛一致，失败和未执行均保留。
3. 只有实际改善有独立证据后才考虑采用候选；之后再评估残差策略或域随机化训练是否必要。

## 协议约束

- 采样前冻结参数来源、单位、联合范围与种子；不根据结果事后收窄范围。
- 训练、调参和最终评测分开；固定控制器评测不包装成策略训练。
- USD 写入与运行时参数独立读回，确认扰动实际生效。
- 成功率、放置误差、倾角、接触和失败原因共同报告；小样本附不确定性，不能外推真机可靠性。
- 随机化验证对假设的敏感性；材料推断和真实参数辨识仍需各自证据。
