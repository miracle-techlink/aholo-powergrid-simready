# 剩余开发项与本轮补齐范围

核查对象：当前代码和真实产物。历史性能提速任务仍按用户指示暂停；不把云端排队、录像、工程分析混成一次新场景的计算耗时。

最新状态以[规范架构路线](../software-architecture.md#开发减法和迁移顺序)和[本轮收口交付](../audits/2026-11-14-remaining-delivery.md)为准。嵌套取消、单机 GPU 租约和杯职责拆分已实现；NeRF2Physics 数值适配／质量候选已接入视频→USD，候选反馈控制已冻结。真实新模型推断、GPU／Docker 集成回归及新留出搬杯物理验证仍未完成。

下表保留初次开发盘点及当时处理范围，不能把它的“本轮”理解为最新状态。后续开发不再重复建设上述执行层；先完成真实环境验收，再扩展自动实例关联、更多模型与场景。

| 优先级 | 需求 | 核查结果 | 本轮处理 / 后续条件 |
|---|---|---|---|
| P0 | 物性扰动与动作鲁棒性 | 此前只有开发方案和固定参数探针 | 本轮增加真实搬杯随机化入口、USD 重读、固定控制器执行、失败计数与置信区间 |
| P0 | 模块边界 | 地面探针从 repair 导入多边形判断，架构检查失败 | 本轮将公共几何函数归入 geometry，保留原导入兼容，恢复分层 |
| P1 | 闭环动作改进 / 域随机化训练 | 现有放置反馈使用仿真真值；没有随机环境训练 | 先观察本轮失败；下一批做限力/滑移反馈或残差策略，冻结训练预算并使用新留出集 |
| P1 | 材料和参数预测 | 分类先验、几何拟合与工程预设；GaussianProperty/NeRF2Physics 尚未真实接入评估 | 需要独立模型环境、来源和公开测量数据；不把现有预设表改名为预测器 |
| P1 | 参数辨识 | 没有真实状态—动作轨迹 | 可先做合成辨识与公开数据实验；真实参数结论依赖可辨识运动或实物数据 |
| P1 | 新视频自动到交付级场景 | 新视频入口可生成候选与巡览；三个交付案例有专用修复 | 仍需实例关联、多视角纹理、可见/未见面的来源约束及独立视觉门槛 |
| P1 | 多场景统一 benchmark | 有协议、评分与审计框架，缺充分标注和密封测试集 | 应冻结带实例、相机、尺度、物性的公开场景清单；不能用三个选中演示计算通用成功率 |
| P1 | 一键视频交付 | 60 秒预览已制作；剪辑、TTS、字幕、混音代码还在 runs，带本机路径 | 后续提取为声明式编辑清单和可移植媒体命令，加入实际音轨和输出校验；不把本轮预览误报为通用产品模块 |
| P2 | 所有资产的可操作性 | 多类分割/物性首版已有，交互只覆盖有限任务 | 柜门、旋钮等需各自关节、碰撞与任务证据 |
| P2 | 通用机器人真实控制 | 统一接口有设备合同，G2 巡览仍是编排运动 | G2 物理导航需策略和适配；固定基座抓杯成绩不能替代导航成绩 |
| P2 | 大规模远端运行 | Docker/本地/SSH 启动代码具备；未完成跨节点生产调度 | 需要可用远端 RTX 节点做完整复现，再接队列、对象存储与故障恢复 |
| P2 | 研究分支替代底稿 | VGGT→gsplat 有训练与评测，尚未达到内部交付门槛 | 需要新的训练/留出评测；现有 Aholo 成片不得记为研究分支成绩 |

本轮选择能独立验证、无需实物或新增服务凭证的第一项，并修复已发现的分层错误。没有把研究模型接入、机器人策略训练、真实物性标定或所有剩余需求标成已完成。
