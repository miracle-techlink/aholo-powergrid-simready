# 封装发布与后续需求状态

状态核对日期：2026-11-13。性能优化已暂停；当前新增工作范围是多类语义资产、逐物体物性与独立验证。

中文竖版白皮书已按视频到 Demo 的技术主线重组，工程命令与字段集中到附录；运行代码和实验数据沿用 v0.7。见[白皮书发布页](https://github.com/miracle-techlink/video-to-simready/releases/tag/technical-report-2026-11-13-v5)与[流程总览](report/pipeline-overview.md)。

物性估计与验证的[长期开发计划](plans/physical_properties.md)保留研究、公开数据评估与条件化辨识。当前已实现[多类首版](physical-assets.md)：真实分割模型、RGB-D 观测、逐对象参数、USD 写入和独立检查，以及实际 PhysX 合成响应。预设参数仍未升级为真实物性标定结果。

## v0.8 多类资产首版

三个子 agent 与主 agent 按文件边界并行开发，提供 `simready workflows semantic-assets` 入口、[公开语义夹具](../examples/semantic_assets/README.md)和[五类物性／动力学夹具](../examples/physical_assets/README.md)。默认 Grounding DINO + SAM 在变电站与星巴克图像上真实运行；SegFormer B0/B5 保留作对照。物性写入支持逐对象接触材质、质量、质心、惯量和运动模式，兼容原 scene spec v1。

真实测试覆盖 USD 独立重读、篡改拒绝、输入哈希竞态、原按钮空间保护、地面重复碰撞拒绝和同视角 RGB-D。合成 PhysX 响应 9 项通过；这不是新一轮变电站机器人任务，也不是实测物性验证。语义误检、完整实例／网格、所有关节和跨场景真值 benchmark 仍需继续完善。

## 并行方式

本次三个子 agent 分别负责分割与 RGB-D、物性写入与响应探针、独立验收；主 agent 负责三维关联、入口、跨模块审查、文档和交付。共享代码按文件明确分工，GPU 任务排队，代码与 CPU 测试并行。接口和源码身份冻结后保存运行证据，失败运行不覆盖。
