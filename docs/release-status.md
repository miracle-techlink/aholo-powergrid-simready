| 跨场景统一 benchmark | 协议、评分、资产图、独立验收和回归框架已实现；尚缺有足够标注与密封测试的多场景数据集及统计结果。 |
| 全资产一致性与全部交互验证 | 已有多类资产和控件候选；当前20项审计覆盖一个选定按钮任务，不能证明所有柜门、旋钮、按钮都正确且可操作。 |
| 修复插件全面自动接入 | 目录、调度、Agent、Memory/Skill框架已有；真实重建/纹理/几何等插件仍未覆盖任意输入和全部缺陷。 |

| 大规模多场景基础设施 | 当前有进程监督、DAG、资源租约和本地缓存；尚不是完整跨节点集群、对象存储与生产调度服务。 |

| 新视频完整E2E基准 | 已纠正历史云任务断线被计为计算的问题；尚未新增同口径的完整云重建到任务视频实测。 |

建议下一阶段先固定多场景测试集与独立验收门槛，再逐个补齐真实修复插件和自动资产化。新增机器人按构型单独做任务验证；集群扩展建立在单任务可重复通过的基础上。性能优化等待用户恢复指令。

## 并行方式

三个子agent分别负责代码构造核查、质量/经验说明与技术方法图；主agent负责集成、实际GPU执行、证据核验与发布。共享代码按文件明确分工。GPU任务由主agent统一排队；代码、CPU测试、报告可并行。接口冻结后再启动相应物理回归，避免测试过程中代码改变。
