[results.json](results.json)保存模型版本、七轮识别对照、源码身份、逐阶段时间和失败说明。[physical-response.csv](physical-response.csv)是实际 PhysX 964 条轨迹，图见[响应曲线](../../report/figures/physical_response.svg)。相关路径记录原始运行来源，私有场景和权重不随本目录发布；公开复现使用[合成夹具](../../../examples/physical_assets/README.md)或[语义入口](../../../examples/semantic_assets/README.md)。

没有语义像素真值，因此不报告 mIoU、实例召回率或真实物性准确率。变电站新观测仍存在设备附件误判为桌子的候选；星巴克存在海报误判为柜体。独立 USD 审计只证明输入声明被正确写入，不能清除这些缺陷。
