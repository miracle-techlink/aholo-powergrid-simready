# 变电站重放与性能实测

2026-11-12。基于 v0.4 `cc65abc8`，计时与适配代码为 `bc69f2b`。本次复跑没有证明模块化带来加速：核心阶段合计由 **718.52 秒变为 743.63 秒（+3.49%）**。同一 GB10 上有既有 Isaac streaming/桌面负载，每种配置仅测一次，不能把差异归因于代码重构，也不提供 p50/p95。[机器可读记录](../benchmarks/substation_profile_20261112.json)

## 范围与方法

- 源视频：91.626 秒、1280×720。重新抽帧、SAM 表面关联、地面与碰撞、Mesh/PBR、原片配准与清晰来源选择、两个修复候选、三个候选原生观测、DINO/边缘/灯位反馈、交互资产、显式估计柜面补全。
- Aholo 模型、柜面平面锚点、已审核的 UV/控制件表和机器人合同为冻结输入。没有新的云端提交；历史成功作业 3610.90 秒不计入本轮。VGGT/gsplat、Difix 不属于当前最终影片的必经分支。
- 三轮实际执行均禁用缓存：A 为旧部署脚本/资产，B 为重建资产加内部 host timer，C 为重建资产加模块化 DAG、无内部 timer。每轮都新跑导航、视觉定位、Z1 接触按压、独立审计、完整渲染。
- 相同物理步长、控制频率、机器人、相机及渲染设置；视频均为 1920×1080、25fps、714 帧。内部 timer 是 inclusive host wall，嵌套区间不能相加当成 CUDA kernel 时间。

## 对照结果

| 阶段 | A：旧部署 | B：内部计时 | C：模块化无内部计时 |
|---|---:|---:|---:|
| 物理，包含进程启动/退出 | 269.01 s | 297.75 s | 296.54 s |
| 独立审计 | 3.15 s | 3.42 s | 3.35 s |
| 完整视频录制 | 446.37 s | 445.99 s | 443.74 s |
| 阶段之和 | 718.52 s | 747.16 s | 743.63 s |

这些是阶段墙钟之和；旧审计与录制启动有轻微重叠，不当作连续关键路径墙钟。旧任务 `wall_s` 只计内部循环，也不能与完整进程时间混用。模块化 DAG 的真实总墙钟及排队另存原始结果。

资产配方的第 0/1/2 轮分别为 **54.74 / 111.46 / 2.94 秒**，合计 169.13 秒（含一次 H.264 解码失败及成功重试），成功尝试合计 167.71 秒。原始配准脚本在 Isaac Python 的 OpenCV 中无法解码，改用 CPU 视频解释器后完成。失败没有从账本中删除。

另做旧抽帧对照 4.43 秒，新抽帧 7.44 秒；在此视频上均输出 136 帧且顺序哈希、划分一致。旧实现哈希距离按字节计算、新实现按位计算，因此不推断其他视频也会输出同一组帧。

资产尝试量加 C 的核心阶段约 **912.77 秒（15.21 分钟）**，这是不同分段实测相加，不是一次从原片开始无中断、冷云端的完整流水线墙钟。全部对照与失败工作量 2382.88 秒，首末 worker 跨度 2785.35 秒。

## 成本与质量

本次固定配方 worker 未调用 LLM，场景执行 token 为 0。它没有测试 Agent/RSI 自主决策，因此不能用 0 宣称 token 优化成功。工程排查有单独的逐次累计差分账本，区分缓存输入、未缓存输入、输出与统计截至时刻；未公开会话日志或认证资料。历史可比 token 账本不存在，节省比例未知。

121 个按钮、49 个旋钮定义一致；1030 个物理 prim 仅有约 2.22e-16 米浮点变换差异，低于比较前设定的 1e-12 容差。三轮任务独立审计均 20/20，通过实测接触停止模拟负载。两次新版本的完整轨迹数组与 A 完全一致。

三条视频完整解码通过。22 对保存的检查 PNG 全帧平均绝对误差范围 0.164–0.254/255，PSNR 52.55–55.72 dB；没有宣称逐像素一致或原片保真。已查看新旧全景、近景按压和回撤画面，未发现明显视觉回归。

DINO 原片一致性改善，但左右柜面的高清来源覆盖仅约 45.57% / 45.40%；整面覆盖与晋升门槛仍失败。完整源资产身份、遮挡、新视角、真实电气功能尚未全部验证。显式估计补全继续保留估计标记，`release_authorized=false`。

## 实测热点与后续实验

| 热点 | B 的 inclusive host wall | 判断 |
|---|---:|---|
| 渲染子帧 | 391.26 s | 优先减少中间修复轮的重复全片渲染；最终覆盖与录制仍完整 |
| 物理步进，14264 次 | 181.56 s | 分析调度和同步，保持物理步长/接触判据 |
| tensor 转 host，198867 次 | 14.14 s | 可研究批量读取与设备端状态处理；需重新做轨迹等价性验收 |
| 编码管道写入 | 8.44 s | 非主要瓶颈，单独优化不能解决整体耗时 |
| ONNX 运动策略 | 0.11 s | 当前不值得优先扩 GPU |

常驻渲染进程、不可变资产缓存和局部视角失效是下一批实验候选，本次没有把尚未实现的优化写成既成加速。已添加可复用计时工具和外部 worker 适配器；它们不能代替未完成的任意视频部署接入。用法见 [profiling 说明](../profiling.md)。

验证：146 项 portable tests，Ruff、架构合同、compileall、wheel/sdist 构建通过；Python 3.10/3.12 CI 通过。原始视频、权重、完整场景产物与工程用量明细保留在本机交付目录，不进入仓库。
